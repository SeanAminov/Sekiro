# Sekiro

A text adventure in Java inspired by Sekiro: Shadows Die Twice, the 2019 Game of the Year. I made it in high school.

## What it does

- You wake at the bottom of a well as Wolf and fight your way out to reach Kuro, the Divine Heir.
- Fights are turn-based duels that show your stats and the enemy's, against spear and sword bearers, an elite samurai, Genichiro and his bodyguard.
- Winning earns money for the shop, and a mission list tracks where you are in the story.
- The story plays out in the console, with Swing windows that show images along the way.

## Run it

```
javac *.java
java SekiroRunner
```

Close each image window to keep the story going.

## Built with

Java, Swing
